# B13-A02

A small responsive web page project built with HTML and CSS. The project contains a main `index.html` file and separate CSS files for styling and responsive behavior.

## Project structure

- index.html — main page
- style.css — primary styles
- responsive.css — responsive layout rules
- assets/ — images and other static assets

## Tech

- HTML
- CSS

## How to view

1. Clone or download the repository:

   git clone https://github.com/raselranar/B13-A02.git

2. Open `index.html` in your web browser.

## Notes

- The layout is responsive; see `responsive.css` for media queries.
- Add or update assets in the `assets/` folder.
